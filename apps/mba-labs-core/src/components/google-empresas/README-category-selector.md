# Seleção de categorias do Google Empresas

- A categoria principal usa uma lista pesquisável.
- O usuário pode digitar para filtrar e selecionar uma opção.
- Uma categoria não presente na lista também pode ser informada manualmente.
- As categorias secundárias são adicionadas como etiquetas removíveis.
- Ao salvar, o formato permanece compatível com o campo `categorias_secundarias` já usado pelo painel.
