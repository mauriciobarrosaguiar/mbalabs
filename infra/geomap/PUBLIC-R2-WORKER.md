# Dedicated public R2/NodeODM integration worker
Requires dedicated Linux host, Docker, Git, Python 3.11+, AWS CLI v2, curl, jq, GDAL. Not deployed; no server purchased. Run only one instance at a time on a controlled host with a separate scoped R2 token injected through secret configuration. Never put secrets in GitHub or public CI. Requires GEOMAP_PUBLIC_WORKER_ENABLE=yes, R2_ENDPOINT, R2_BUCKET_NAME=mba-geomap, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY. Run python3 infra/geomap/public-r2-worker.py.
The 29 licensed Mygla images (155,493,827 bytes) are fixed by Git blob checksums and source commit. Worker transfers into an isolated random prefix, verifies roundtrip, feeds downloaded originals to existing pinned NodeODM smoke workflow, uploads output, compares hashes, removes all test objects and checks absence. The public integration test cleans immediately; normal production retention remains 168h after availability. No private inputs, no general upload, no persistent job queue yet. 8 GB preflight inventory and max 500 MB output are conservative local checks, not atomic reservations or a global cost cap; abort if inventory exceeds 1000 objects. Failed or interrupted cleanup may require manual review; durable cleanup pending. No live R2 worker execution until compute host and credentials authorized.
